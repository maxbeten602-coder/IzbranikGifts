ЗАПУСК БОТА НА СВОЁМ ПК (Windows)

1) Установи Python 3.10 или новее: https://www.python.org/downloads/
   В установщике ОБЯЗАТЕЛЬНО поставь галочку "Add python.exe to PATH".

2) Распакуй архив в постоянную папку (например C:\NexvenBot) и дважды кликни  start_bot.bat
   При первом запуске он сам поставит всё нужное и спросит:
     - токен бота (из @BotFather)
     - ссылку на мини-апп (GitHub Pages, с https://)
   Ответы сохранятся в файл .env — больше спрашивать не будет.
   В окне должна появиться строка:  Bot starting as @nexvendrop_bot
   Окно не закрывай — пока оно открыто, бот работает. Если бот упадёт, он перезапустится сам через 5 секунд.

3) Автозапуск при включении ПК: один раз запусти  autostart_install.bat  (убрать: autostart_remove.bat).

4) ВАЖНО:
   - ОСТАНОВИ бота на Railway (Settings -> Danger -> Remove service, или Deployments -> Remove). Один токен = один бот.
     Если запущены две копии — будет ошибка "Conflict: terminated by other getUpdates request".
   - Не давай ПК уходить в сон/гибернацию (Параметры -> Система -> Питание: «Никогда» при питании от сети),
     иначе бот будет молчать. Интернет должен быть включён. Открывать порты / настраивать роутер НЕ нужно.
   - Данные игроков, рефералы и баны лежат в папке db рядом с ботом. Не удаляй её. Копируй её для бэкапа.

5) Обновление: останови бота (закрой окно), замени файлы новой версией (папку db и файл .env НЕ трогай),
   запусти start_bot.bat.

6) Проверка Firebase: напиши боту /fscheck (должно быть WRITE 200 / READ 200).

КОМАНДЫ АДМИНА В БОТЕ
   /ban <id или @username> [срок] [причина]
        срок: 30m (минуты) · 2h (часы) · 7d (дни) · 2w (недели) · навсегда. Без срока — навсегда.
        /ban 123456789 7d спам          /ban @nick 2h оскорбления          /ban 123456789 навсегда читерство
   /unban <id или @username>  — снять бан      /bans — список (ещё и кнопка «Баны» в Админ-панели)
   /refreset <id>  — снять привязку реферала    /fscheck — проверка Firebase
В МИНИ-АППЕ: Профиль -> Админ-панель -> «Баны» (ID, срок, причина).

ЧТО ВИДИТ ЗАБАНЕННЫЙ
   Мини-апп: всё размыто, поверх окно «Вы заблокированы» со сроком и обратным отсчётом (до окончания), причиной и кнопкой поддержки.
   Бот: сообщение о бане со сроком и причиной; любые его действия в боте блокируются. Когда срок истекает — бан снимается сам и приходит сообщение.

=====================================================================
АДМИН: только 8133917568 (и в боте, и в мини-аппе). Остальные ID убраны.
   Старый файл .env на ПК перезапиши файлом .env из этого архива (в нём уже новый токен бота и админ).
   Если бот ещё где-то запущен (Railway и т.п.) — там тоже поменяй BOT_TOKEN / OWNER_ID / ADMIN_IDS или останови.

КОНСОЛЬ ВЫБОРА БАЗЫ
   Открой open_console.bat (или в браузере http://127.0.0.1:8787/console — только на этом ПК).
   Две большие кнопки: «Firebase» и «ПК». Один клик — бот и мини-апп переходят на выбранную базу,
   лидерборд / онлайн / баны / награды / промокоды «оживают» на новой базе. То же самое: команда /db в боте.
   Кнопки: «Проверить Firebase» (покажет причину ошибки, например 429), «Проверить доступ из интернета»,
   «Импорт Firebase → ПК» (скопирует игроков, сохранения, баны, промокоды; при исчерпанной квоте остановится и скажет).

КАК ЗАСТАВИТЬ РАБОТАТЬ РЕЖИМ «ПК» ДЛЯ ИГРОКОВ (один раз)
   Телефонам игроков нужен адрес твоего ПК из интернета. Для этого — бесплатный туннель ngrok с постоянным доменом:
   1) Зарегистрируйся на ngrok.com, в разделе Domains создай бесплатный домен (вида abc-def.ngrok-free.app).
   2) Запусти start_tunnel.bat — он подскажет, как поставить ngrok, и спросит домен (запомнит в tunnel.txt). Окно не закрывай.
   3) В config.js мини-аппа впиши:  pcApi: 'https://abc-def.ngrok-free.app'  и выложи сайт на GitHub Pages заново.
   4) В .env бота добавь:  PUBLIC_URL=https://abc-def.ngrok-free.app  (нужно только для кнопки проверки в консоли).
   Дальше всё само: приложение раз в минуту спрашивает у ПК, какая база активна.
   Если ПК выключен или туннель не запущен — приложение автоматически работает на Firebase.

ВАЖНО ПРО ДАННЫЕ
   Режим «ПК» хранит данные в db/localfs.json (делай копию папки db). Режимы НЕ синхронизируются между собой:
   что записано на ПК — не попадает в Firebase автоматически (есть только импорт Firebase → ПК).
   Баны дублируются в обе стороны только в том режиме, который активен.

ТОКЕН БОТА лежит в файле .env. Никому его не показывай. Если токен утёк — BotFather → /revoke и вставь новый в .env.
